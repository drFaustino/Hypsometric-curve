description=This plugin calculates the hypsometric curve of a drainage basin using a DEM raster layer and a vector polygon representing the basin boundary. It allows selecting the number of elevation classes, computes partial and cumulative areas, minimum, maximum and mean elevation, and the Hypsometric Integral (HI). The plugin also generates the hypsometric curve graph and provides export options for both the table (CSV/TXT) and the graph (PNG/JPG). It requires NumPy and Matplotlib.
